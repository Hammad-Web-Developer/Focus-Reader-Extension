# Focus-Reader-Extension

^^ Kind of MVP of my focus reader extension ^^

A browser extension designed to help users read PDFs with greater focus by displaying text progressively and highlighting the current reading position.

## Current Status

🚧 In development

## Planned Features

- PDF text extraction using PDF.js
- Word-by-word / guided reading
- Adjustable reading speed
- Current-word highlighting
- Page and line navigation
- Focus mode with reduced visual distraction

## Comment

The UI for extension is pretty much finished.
You have to provide *.pdf file and page number you wanna read from and popup.js gets contents as bytes by arrayBuffer method.
I have yet to write code that highlights and displays that content.
